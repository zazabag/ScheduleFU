# Исходники экранов

Рабочие файлы дизайн-канваса ScheduleFU. Канвас опубликован отдельно;
эти файлы — источник правды, из них он пересобирается.

| Файл | Экран |
|---|---|
| `Main.dc.html` | свободные аудитории (главный) |
| `Schedule.dc.html` | расписание группы |
| `GroupPicker.dc.html` | выбор и закрепление группы |
| `Lecturer.dc.html` | где преподаватель сейчас |
| `SketchB/SketchC.dc.html` | первые наброски направлений, для сравнения |
| `canvas.json` | раскладка канваса |

Направление — **тёмная «лента времени»** (SketchC): полоса показывает день
по шести парам, видно не только «свободна», но и когда освободится.
Шрифт Space Grotesk, акцент `#c8fa5f`.

Данные в файлах — реальная выгрузка из базы проекта за неделю
14—19.09.2026. Единственное подставленное значение — метка «изменено» на
паре в среду: сборщик сделал один проход, сравнивать было не с чем.
