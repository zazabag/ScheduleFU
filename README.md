# ScheduleFU — свободные аудитории Финансового университета

## Идея

Сервис, который показывает, какие аудитории главного корпуса Финансового
университета при Правительстве РФ (Ленинградский проспект, 49) свободны
прямо сейчас. Полезен студентам (найти, где позаниматься) и преподавателям
(найти место для внеучебной активности). Логика: собрать базу аудиторий,
стянуть расписание всех групп, сравнить с текущим временем и показать
результат. Форма подачи (сайт, Telegram-бот) — вопрос второй, пока не
принципиален.

## Статус на 11.09.2026

Проведено ресёрч-исследование гипотезы: проверена техническая
реализуемость, найден рабочий источник данных, оценены юридические риски,
намечена механика и план развития. Разработка ещё не начата. Все находки —
в папке `docs/`, дальнейшая работа продолжается в Claude Code с этой
папкой как рабочей директорией проекта.

## Структура

- `docs/03-legal-risks.md` — юридические риски и как их снижать

## Ключевой вывод одной строкой

Система расписания вуза (`ruz.fa.ru`) открыта без обязательной авторизации,
и под неё уже есть готовые сторонние обёртки — техническая часть посильна.
Главные риски — не уголовные, а по праву на базу данных вуза (ст. 1334 ГК
РФ), и решаются через диалог с университетом, а не через скрытный парсинг
всей базы.

## Область первого MVP

Главный корпус (Ленинградский проспект, 49). Остальные корпуса — потом,
расширением справочника аудиторий: источник расписания, судя по всему,
общий для всего вуза.
