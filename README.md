# ScheduleFU

Расписание Финансового университета: свободные аудитории, расписание
группы и преподавателя. Неофициальный проект, с администрацией вуза не
связан.

**Открыть: https://zazabag.github.io/ScheduleFU/**

## Что умеет

- **Свободные аудитории сейчас** — по корпусам и этажам, с полосой
  занятости на весь день и подписанным временем каждой пары. Этого у
  `ruz.fa.ru` нет вовсе.
- **Расписание группы** — без логина, выбранная группа запоминается в
  браузере.
- **Где преподаватель сейчас** — в какой аудитории идёт его пара.
- **Уведомления об изменениях** — вуз правит расписание задним числом и
  никого не уведомляет; сборщик ловит правки сравнением слепков и шлёт
  одно сообщение с итогом, а не по уведомлению на каждую правку.
- **Установка на телефон** — приложение ставится на рабочий стол и
  открывается без браузерной обвязки, оболочка работает без сети.
- **Подписка в календаре** — расписание группы или преподавателя
  подхватывается любым календарём и обновляется само раз в час.

## Две версии

| | Где работает | Данные |
|---|---|---|
| **Статическая** (`cmd/staticgen`) | GitHub Pages | замораживаются в момент выкладки |
| **Серверная** (`cmd/api`) | свой хост, нужен PostgreSQL | обновляются сборщиком |

Статическая версия существует потому, что Pages раздаёт только файлы:
запустить там Go и базу нечем. Данные выгружаются в JSON по дням, а
расчёт «свободно сейчас», фильтры и поиск считает браузер.

## Запуск

Один бинарник, настройки — YAML плюс переменные `SCHEDULEFU_*` поверх
(секреты только в окружении):

```bash
createdb schedulefu
go build -o schedulefu ./cmd/schedulefu
./schedulefu migrate
./schedulefu seed -data data                 # 773 аудитории, 479 групп
./schedulefu collect -once -no-notify        # первое наполнение
./schedulefu serve                           # http://localhost:8090
```

Сборщик в цикле: `./schedulefu collect` (интервал из конфига). Пример
конфига пишет `deploy/local/install.sh`; на macOS он же ставит службы.

### Уведомления

Ключи создаются один раз; при их смене все подписки перестают работать.

```bash
./schedulefu vapid > ~/.schedulefu/env       # приватный ключ не коммитить
export $(cat ~/.schedulefu/env | xargs)
./schedulefu serve
```

Статическая версия для Pages подписки принимать не может — там нет
сервера; собрать её с адресом работающего:

```bash
SCHEDULEFU_STATIC_API_BASE=https://адрес ./schedulefu static
```

## Устройство

Модульный монолит по [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md):
`presentation → modules → platform`, модули `source · schedule · notify ·
export` с портами между ними, один писатель у таблицы. Граф зависимостей
держит тест `internal/archtest`.

## Известные ограничения

- **Брони вне расписания не видны.** Мероприятия, экзамены и ремонт вуз в
  `ruz.fa.ru` не публикует, поэтому аудитория, помеченная свободной, может
  быть занята. Предупреждение показывается на экране, а не прячется в
  настройках.
- **Языковые занятия могут не попасть в расписание группы.** У них пустой
  поток, а в поле группы лежит код подгруппы вроде
  `006886_1 Иностранный язык (КАЯиПК)-1` — связи с основной группой в
  данных нет.
- **Названий факультетов не существует** в открытом виде: источник отдаёт
  только числовой идентификатор.
- **Статическая версия показывает данные на момент выкладки**, а не
  текущие, и не умеет ни принимать подписки на уведомления, ни отдавать
  календарь: на GitHub Pages нет сервера. Уведомления появляются при
  сборке с `-api-base`, календарь доступен только в серверной версии.
