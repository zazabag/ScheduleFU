# Разовые инструменты сбора справочников

Скрипты на Python — намеренно одноразовые: справочники меняются раз в
семестр, а рабочий код проекта пишется на Go. Результаты лежат в `data/`
и коммитятся, чтобы сборку не надо было повторять на каждой машине.

| Скрипт | Что делает | Результат |
|---|---|---|
| `discover_auditoriums.py` | поиск по префиксам + перебор `oid` | `data/auditoriums.json` (773 аудитории) |
| `discover_groups.py` | перебор «год-номер» | `data/groups.json` (479 групп) |

Оба ходят в чужой сервер: держат паузу между запросами и небольшой пул
потоков. Полный сбор аудиторий — около 12 минут, 5214 запросов.

Замечание: поле `floor` в `auditoriums.json` посчитано устаревшим наивным
правилом и не используется. Разбор этажей живёт в `internal/ruz`, где
правила заданы по корпусам.
